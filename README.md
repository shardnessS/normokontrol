# normokontrol-mcp

MCP-сервер для оформления и проверки учебных и научных работ по ГОСТ 7.32-2017
и ГОСТ Р 7.0.100-2018: сборка `.docx` из Markdown, список литературы,
проверка как у нормоконтролёра и автоисправление.

Инструмент **оформляет** работу, а не пишет её. Финально сверяйтесь с методичкой вуза.

> Проект в разработке. Установка — [docs/install.md](docs/install.md).
