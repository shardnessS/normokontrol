# normokontrol

Набор скиллов для Claude: оформление и проверка учебных и научных работ по ГОСТ 7.32-2017
и ГОСТ Р 7.0.100-2018 — требования к оформлению, список литературы, а дальше сборка `.docx`
и проверка как у нормоконтролёра.

Инструмент **оформляет** работу, а не пишет её. Финально сверяйтесь с методичкой вуза.

> Проект в разработке. Установка — [docs/install.md](docs/install.md).
