# Журнал архитектурных решений

Формат: дата — решение — причина.

## 2026-09-30 — Название `normokontrol-mcp`

Рабочее имя `gost-mcp` заменено на `normokontrol-mcp`.

- «GOST» неоднозначно (семейство криптоалгоритмов, прокси-проекты), на GitHub уже есть `mcp-gost` и `gost-standardizer-mcp`.
- «Нормоконтроль» точно описывает назначение инструмента; транслитерация по ГОСТ 7.79-2000 (система Б). Вариант `normocontrol` из черновика ТЗ — смесь транслитерации и английского.
- Имя свободно на PyPI и GitHub (проверено 2026-09-30).

Производные имена: пакет `normokontrol_mcp`, команда `normokontrol-mcp`, переменные окружения `NORMOKONTROL_*`, схема ресурсов `normokontrol://`.

## 2026-09-30 — MCP SDK 2.x: `MCPServer` вместо `FastMCP`

В `mcp` 2.x класс `FastMCP` переименован в `mcp.server.mcpserver.MCPServer`, API декораторов тот же. Используем `mcp>=2.2,<3`. В ТЗ «FastMCP» читать как `MCPServer`.

## 2026-09-30 — MCP Inspector на Windows и `uvx`

`npx @modelcontextprotocol/inspector --cli uvx --from . normokontrol-mcp` на Windows закрывает соединение, хотя тот же запуск `uvx` работает с MCP-клиентом Python SDK (stdio). Для отладки используем `npx @modelcontextprotocol/inspector uv run normokontrol-mcp` (как в CLAUDE.md) — работает. Причина, вероятно, в способе запуска дочернего процесса Inspector'ом; к серверу не относится.

## 2026-09-30 — Сверка правил с ГОСТ 7.32-2017 (этап 1)

Раздел 5 SPEC переписан по тексту раздела 6 стандарта. Существенные исправления:
- Структурные элементы: добавлен «СПИСОК ИСПОЛНИТЕЛЕЙ», «ПЕРЕЧЕНЬ СОКРАЩЕНИЙ» → «ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ» (6.2.1).
- Перечисления: тире, а не дефис; допускаются также цифры со скобкой (6.4.6).
- Выравнивание по ширине и нулевые интервалы до/после абзаца в ГОСТ отсутствуют — оставлены в базовом пресете с пометкой «Не ГОСТ».
- Кегль: ГОСТ требует не менее 12 пт; базовый пресет собирает в 14 пт, для проверки хранит `min_size_pt: 12`.
- Добавлены требования, которых не было: нумерация объектов в приложениях (`Рисунок А.3`, `(В.1)`), одинарный интервал в многострочных подписях, свободная строка вокруг формул, латинские буквы приложений.
- Типографика (тире, кавычки, неразрывные пробелы) — не из ГОСТ 7.32, в проверке будет предупреждениями.
- Открыто: точный знак тире в подписях «Рисунок 1 — …» (TODO(verify)).

## 2026-09-30 — Схема пресета: `{num}`, `sources`, наследование метаданных

- В шаблонах подписей используется `{num}` — готовый номер, а не `{n}`/`{chapter}.{n}`: вид номера задаётся `numbering`, что исключает противоречивые комбинации.
- Поле `sources` (путь параметра → пункт документа) вместо отдельного `source` у каждого правила: значения остаются простыми, `get_rules` показывает источник рядом с каждым требованием.
- `verified` и `source_docs` не наследуются: пресет вуза не может случайно получить `verified: true` от базового.
- Ресурс `normokontrol://presets/{id}` отдаёт пресет после применения наследования.
